# Galería Pokémon

Sitio web dinámico que muestra una galería de los 151 pokémon de la primera generación. Desarrollado como desafío práctico del curso **Programación Front End · TI3V31 · Unidad 1**.

## Demo en vivo

🔗 **[Ver sitio publicado](https://walthermorarivers.github.io/mi-galeria-web/)**

## Qué hace

- Consume la [PokéAPI](https://pokeapi.co) con `fetch` y `async/await`
- Muestra tarjetas con imagen oficial, número, nombre y tipos de cada pokémon
- Buscador en vivo que filtra por nombre mientras escribes
- Toggle de modo oscuro / claro con variables CSS
- Diseño responsivo (CSS Grid + media queries)
- Manejo de errores con `try/catch` y `response.ok`
